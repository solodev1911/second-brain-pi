## [0.1.0-beta.1] - 2026-09-19

### Added

- Global Pi package with repository-isolated Graphify graphs.
- Explicit `/remember` capture of the latest completed answer.
- `/memory-status`, `/graph-refresh`, and `/second-brain-doctor` commands.
- Eight bounded graph retrieval and inspection tools.
- Source-linked Markdown memories with exact deduplication and atomic publication.
- Fresh-session recall, Graphify contract, Pi RPC, live-model, and packed-install test harnesses.
- Automatic locked Graphify environment provisioning through `uv`.
- Apache-2.0 licensing, third-party notices, public security and contribution policies, and structured GitHub templates.
- macOS and Linux CI plus npm trusted-publishing automation with provenance.

### Changed

- Updated the bundled Graphify runtime to the patched `0.9.64` baseline.
- Refreshed locked Python transitive dependencies to security-fixed versions.
- Prepared the npm artifact for one-command public installation.
