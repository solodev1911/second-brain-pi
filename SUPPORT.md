# Support

Second Brain is a community-maintained open-source project.

For setup or usage help:

1. Read the [README](README.md) and [troubleshooting guide](docs/troubleshooting.md).
2. Run `/second-brain-doctor` inside the affected repository.
3. Search [existing issues](https://github.com/solodev1911/second-brain-pi/issues).
4. Open a [bug report](https://github.com/solodev1911/second-brain-pi/issues/new?template=bug.yml) with sanitized diagnostic output if the problem persists.

Please do not include secrets, proprietary source, memory contents, or personal filesystem paths. Security vulnerabilities belong in a [private security report](SECURITY.md), not a public support issue.

There is no guaranteed response time or service-level agreement.
